# Meertalig royketelaar.nl — ontwerp

Datum: 2026-08-16. Status: goedgekeurd door Roy (keuzes: variant A, Engels blijft, @nuxtjs/i18n, Frysk als concept door Claude, geen browsertaal-omleiding).

## Doel

De site is beschikbaar in Nederlands (standaard), Frysk en Engels. Elke taal heeft een eigen URL. De taalkeuze voldoet aan WCAG 2.2 AA.

## URL's en routing

| Taal | Code | URL | `<html lang>` |
| --- | --- | --- | --- |
| Nederlands | `nl` | `/` | `nl` |
| Frysk | `fy` | `/fy` | `fy` |
| English | `en` | `/en` | `en` |

- Module `@nuxtjs/i18n` (v10), `strategy: 'prefix_except_default'`, `defaultLocale: 'nl'`, `baseUrl: 'https://royketelaar.nl'`.
- `detectBrowserLanguage: false`. Geen omleiding, geen cookie.
- `useLocaleHead()` in `app.vue` zet `lang`, de `hreflang`-alternates (incl. `x-default` = nl) en `og:locale`. De vaste `htmlAttrs.lang: 'en'` in `nuxt.config.ts` vervalt.
- Prerender: `/` staat in `nitro.prerender.routes`; `crawlLinks` vindt `/fy` en `/en` via de taalkeuze.

## Inhoud

- Markdown per taal: `content/nl/index.md`, `content/fy/index.md`, `content/en/index.md`. Zelfde structuur als nu (frontmatter `title`, `description`; body met h1, h2, tekst, h3-lijsten). Studio blijft werken.
- `content.config.ts` blijft één collectie `content` (`**/*.md`); de pagina vraagt `path('/' + locale)`.
- UI-teksten in `i18n/locales/{nl,fy,en}.json`: `lang.label`, `contact`, `github`, `linkedin`, `terms`, `privacy`, `portrait`, `meta.title`, `meta.description`.
- De PDF's blijven Nederlands. Zichtbare linktekst: NL "Algemene voorwaarden (PDF)", FY "Algemiene betingsten (PDF, Nederlânsk)", EN "Terms and conditions (PDF, Dutch)". Links krijgen `hreflang="nl"`. De aparte `aria-label`s op deze links vervallen (zichtbare tekst is de naam; WCAG 2.5.3).
- Roy leest het Frysk na voordat het live gaat.

## Taalkeuze (variant A)

Component `app/components/LanguageSwitcher.vue`:

- `<nav :aria-label="t('lang.label')">` met `<ul>` en per taal een `NuxtLink` naar `switchLocalePath(code)`.
- Elke link: zichtbare naam in de eigen taal (Nederlands / Frysk / English), `lang` en `hreflang` = code, `aria-current="true"` op de actieve taal.
- Stijl: pil op `bg-stone-50/85` met lichte schaduw en blur, `absolute right-4 top-4 md:right-8 md:top-8` binnen `<main class="relative">` (scrolt mee). Links: `min-h-8`, `rounded-full`, `px-2.5`, tekst `text-stone-950`, hover `bg-stone-200/90`, actief `bg-red-900 text-white font-semibold`, focus `focus-visible:outline-2 outline-offset-2 outline-red-900`.
- Het is het eerste element in de DOM en de tabvolgorde, vóór `<main>`-inhoud.

## Pagina

`app/pages/index.vue`:

- `const { locale, t } = useI18n()`; `useAsyncData(() => 'home-' + locale.value, () => queryCollection('content').path('/' + locale.value).first())` (reactieve sleutel, dus herladen bij taalwissel).
- Alt-tekst portret, knoptekst, aria-labels van GitHub/LinkedIn en linkteksten via `t()`.
- `useSeoMeta` blijft uit de content-frontmatter komen.
- `app.vue`: titel en description via `t('meta.*')` als fallback.
